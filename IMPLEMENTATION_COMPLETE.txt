================================================================================
KEY DESIGN DECISIONS
================================================================================

1. UNIQUE CONSTRAINT ON (user_id, aspect_id)
   - Ensures one entry per user per aspect
   - Enforced at database level via Peewee indexes
   - Prevents accidental duplicates

2. SOFT DELETE FOR UserAspect
   - Preserves history and audit trails
   - Allows easy recovery if needed
   - Uses deleted_at field for temporal tracking

3. IDEMPOTENT SEEDING
   - get_or_create_default_aspects can be called multiple times safely
   - Checks if aspect exists before creating
   - Uses aspect name as unique identifier

4. PROMPT OVERRIDE STRATEGY
   - Custom prompt stored per user (UserAspect.custom_prompt)
   - Default prompt in global Aspect
   - Service layer handles selection logic
   - Allows per-user customization without modifying shared template

5. DEFAULT ASPECT PROTECTION
   - Cannot be deleted via service layer
   - Cannot be modified via service layer
   - AspectDeletionError raised on attempt
   - But can be read and used by any number of users

6. USER ISOLATION
   - All queries filtered by user_id
   - Multiple users can have same aspect with different configs
   - Changes to one user's settings don't affect others
   - Verified with integration tests

HOW TO RUN TESTS
================================================================================

1. Install dependencies:
   pip install -r requirements.txt

2. Run all aspect tests:
   python -m pytest tests/test_aspect_*.py -v

3. Run specific test file:
   python -m pytest tests/test_aspect_models.py -v
   python -m pytest tests/test_aspect_repositories.py -v
   python -m pytest tests/test_aspect_service.py -v

4. Run with coverage:
   python -m pytest tests/test_aspect_*.py \
     --cov=models.aspect \
     --cov=repositories.aspect_repository \
     --cov=services.aspect_service

5. Run short traceback:
   python -m pytest tests/test_aspect_*.py -v --tb=short

6. Verify imports:
   python -c "from models.aspect import Aspect, UserAspect; \
     from repositories.aspect_repository import AspectRepository, UserAspectRepository; \
     from services.aspect_service import AspectService; \
     print('✅ All imports OK')"
