Paper Reproducibility Checker

Automatically evaluate scientific research reproducibility using AI and code execution

📄 About This Project

This tool helps assess whether scientific papers are reproducible by:

  • Extracting code artifacts and methodology from PDF papers
  • Executing code in isolated Docker sandboxes
  • Comparing claimed results with actual execution results
  • Evaluating 15 reproducibility criteria across critical, high-value, and nice-to-have tiers
  • Providing interactive chat for follow-up questions about papers

⚙️ How It Works

📋 15 Evaluation Criteria

Papers are evaluated across three tiers:

🔴 Critical (5)

  • • Dependencies Pinned
  • • Results Reproducible
  • • Hyperparameters Doc.
  • • Dataset Available
  • • Environment Doc.

🟠 High Value (4)

  • • Test Suite
  • • Config File
  • • Documentation
  • • Randomness Control

🟡 Nice-to-Have (6)

  • • License
  • • CI/CD
  • • Data Versioning
  • • Requirements Spec
  • • Version Compat.
  • • Output Format
