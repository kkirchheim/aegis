Paper Reproducibility Checker

Automatically evaluate if scientific papers are reproducible using AI-powered analysis and code execution

📄 About

Automatically evaluate scientific paper reproducibility using AI, code execution, and intelligent analysis.

  • Analyze — Extract code, methodology, and citations from PDF papers
  • Execute — Run code in isolated Docker sandboxes with resource limits
  • Compare — Verify claimed results against actual execution outputs
  • Score — Rate reproducibility across 15 criteria (critical, high-value, nice-to-have)
  • Chat — Ask follow-up questions about papers with full context

📋 Evaluation Criteria

15 criteria across three importance tiers:

Critical (5)

  • • Results reproducible
  • • Dependencies pinned
  • • Environment documented
  • • Hyperparameters documented
  • • Dataset available

High Value (4)

  • • Configuration file
  • • Test suite
  • • Good documentation
  • • Randomness controlled

Nice-to-Have (6)

  • • CI/CD pipeline
  • • License specified
  • • Data versioning
  • • Version compatibility
  • • Output format doc
  • • Requirements spec
