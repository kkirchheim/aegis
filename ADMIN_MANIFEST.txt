API ENDPOINTS REFERENCE
================================================================================

Admin endpoints (all require admin login):

  GET /admin
    → Serves admin panel HTML page
    → Redirects to login if not authenticated
    → Returns 403 if not admin

  GET /api/admin/users
    → Returns JSON array of all users
    → Response: [{id, username, email, is_active, created_at}, ...]

  POST /api/admin/users/<user_id>/activate
    → Activates an inactive user
    → Returns: {ok: true, message: "..."}

  POST /api/admin/users/<user_id>/deactivate
    → Deactivates an active user
    → Returns: {ok: true, message: "..."}
    → Error: Cannot deactivate admin (400)

  POST /api/admin/users/<user_id>/delete
    → Permanently deletes user and all data
    → Returns: {ok: true, message: "..."}
    → Error: Cannot delete admin (400)

Password change endpoint (all users):

  GET /change-password
    → Serves password change form page
    → Requires user login

  POST /api/change-password
    → Changes user password
    → Requires: old_password, new_password, confirm_password
    → Returns: {ok: true, message: "..."}
