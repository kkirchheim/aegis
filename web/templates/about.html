AEGIS

AEGIS is an LLM-assisted software artifact review system for scientific publications. It collects and interprets evidence about the availability, executability, and usability of research artifacts.

Approach

AEGIS models artifact review as a process of evidence generation and interpretation. Starting from a scientific publication, the system extracts referenced artifacts, collects heterogeneous evidence using complementary analysis components, and aggregates the results into a structured, multi-dimensional assessment.

  • Extract — Identify software artifacts, datasets, and resources referenced in the paper
  • Generate Evidence — Collect signals through deterministic checks, semantic evaluation, and interactive exploration
  • Assess — Aggregate evidence into a structured review context for human inspection

Pipeline

  • Upload

    Submit a PDF publication

  • Extract

    Identify artifacts and metadata

  • Generate Evidence

    Run checks, agent, and semantic analysis

  • Assess

    Aggregate into review context

Evidence Generators

Three complementary mechanisms for collecting review evidence:

Deterministic

Repository structure, dependency manifests, configuration files, presence of documentation and scripts. Implemented as execution checks.

Semantic

LLM-based evaluation of documentation quality, resource requirements, and paper-artifact correspondence. Implemented as evaluation plugins.

Interactive

Agentic exploration that follows setup instructions, installs dependencies, and executes scripts in a sandboxed Docker environment.
