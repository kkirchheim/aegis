HEALTH CHECK ENDPOINT DETAILS:

Endpoint: GET /api/health
Location: blueprints/api.py, lines 13-73

Response Format:
{
  "status": "healthy|unhealthy",
  "timestamp": "2024-02-04T14:38:00.000000Z",
  "checks": {
    "flask": true/false,
    "database": true/false,
    "docker": true/false,
    "llm_provider": true/false
  },
  "errors": ["optional error messages"]
}

Status Codes:
  200 OK                 - All critical services healthy (Flask + Database)
  503 Service Unavailable - One or more critical services failed

Health Checks:
  Flask         - Always true (HTTP success indicates Flask is running)
  Database      - Executes "SELECT 1" to verify connectivity
  Docker        - Calls is_docker_available()
  LLM Provider  - Calls init_llm_provider() (optional, non-critical)
